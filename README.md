# Gymory

Offline gym & fitness center register — members, membership plans, monthly fee bills with arrears, printable receipts, check-in register, trainers, body measurements, expenses, defaulters + WhatsApp reminders. Encrypted local database, PIN roles, opt-in LAN sharing. No account, no internet.

## Dev
npm install && npm run dev

## Build (Windows .appx)
npm run dist:win

Set `build.appx.identityName` / `publisher` from Partner Center before building for the Store.
